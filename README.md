📌 Overview

This repository contains a collection of mini C++ projects built to strengthen core programming concepts and problem-solving skills.
These projects are developed as part of internship preparation and continuous learning.
Each project focuses on practical implementation of C++ fundamentals and real-world system logic.

🚀 Projects Included

1️⃣ Library Management System

A console-based application that allows users to:

• Add books

• View book records

• Search books

• Issue and return books


2️⃣ Account Management System

A simple banking console application where users can:

• Deposit and withdraw money

• Check account balance

• Maintain account details


3️⃣ Digital Clock

A console-based digital clock that:

• Displays current system date and time in a clean format

• Helps understand ctime and tm structures in C++

• Demonstrates formatting with <iomanip>


4️⃣ Login Authentication System

A basic authentication system that:

• Stores a username and password

• Checks user input against stored credentials

• Displays appropriate success/failure messages


5️⃣ Simple Calculator

A console-based calculator that:

• Performs basic arithmetic operations (addition, subtraction, multiplication, division)

• Takes input from the user and displays the result

• Demonstrates conditional logic and user input handling


💻 Concepts Practiced

1.Functions

2.Loops and Conditionals

3.Object-Oriented Programming (OOP)

4.File Handling

5.User Input Validation

6.Basic Data Structures

7.Modular Programming


🎯 Purpose

The goal of this repository is to:

→ Build strong fundamentals in C++

→ Improve logical thinking and structured programming

→ Gain hands-on development experience for internships


🛠 How to Run

Clone the repository:

→ git clone <your-repo-link>

→ Open the project folder in your preferred C++ IDE or compiler.

→ Compile the .cpp file for the project you want to run.

→ Execute the compiled program to see it in action.

→ Follow on-screen instructions for each project.
